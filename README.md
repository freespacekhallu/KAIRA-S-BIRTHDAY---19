# Kaira's Birthday Site

A mobile-friendly birthday experience for Kaira, built as a simple VS Code project.

## Project files

- `index.html` — page structure and CDN links.
- `styles.css` — all visual styles and responsive layouts.
- `config.js` — Kaira's name, sender name, birthday message, and optional music path.
- `script.js` — interactions, Happy Birthday music-box tune, game, animations, and procedural Three.js cake.

The music and visuals are generated by the browser code, so there are no required image, model, or audio files. Three.js, GSAP, canvas-confetti, and Google Fonts load from their CDNs, so an internet connection is needed when previewing or sharing the site.

## Open in VS Code

Open this folder in VS Code, edit `config.js`, and open `index.html` in a browser. The supplied `birthday.mp3` is already beside `index.html`, and `config.js` is set to play it. The built-in Happy Birthday tune remains the fallback if the MP3 is missing or unavailable.

## Publish with GitHub Pages

1. Create a GitHub repository and upload `index.html`, `styles.css`, `config.js`, `script.js`, and this README.
2. Open **Settings → Pages** in the repository.
3. Select **Deploy from a branch**, choose your main branch and `/ (root)`, then save.
4. Share the Pages URL shown in the settings after publishing finishes.
